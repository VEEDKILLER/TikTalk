# Diffusion — local SDXL baseline & cartoon-style LoRA

This module contains the **open-weight, locally-hosted** visual-stimulus
generation experiments for TikTalk. It complements the deployed DALL·E 3
production backbone (in `TikTalk-backend/tiktalk_diffusion/`) and provides the
SDXL-Turbo local baseline and the cartoon-style LoRA adaptation reported in the
paper.

All scripts run on an Apple Silicon machine (M4, 16 GB) via PyTorch's **MPS**
backend. Inference uses `torch_dtype=float32` because MPS half-precision
produces black images.

## Scripts → paper mapping

| Script | What it does | Paper reference |
|--------|--------------|-----------------|
| `scripts/01_sdxl_turbo_baseline.py` | SDXL-Turbo (`stabilityai/sdxl-turbo`) inference: 4 steps, `guidance_scale=0.0`, Euler-Ancestral (default), 512×512, attention slicing, MPS, float32. | §4.2.1 *SDXL-Turbo local baseline*; latency/cost in **Table 4**; backbone ablation in **Table 9** |
| `scripts/02_sdxl_base_inference.py` | Full SDXL-base-1.0 inference (25 steps, DPM++, 1024×1024) — heavier reference run. | §2.1 / §4.2.1 (open-weight backbone discussion) |
| `scripts/03_prepare_cartoon_dataset.py` | Downloads 50 images from the HF `bunyi/cute-style` dataset, resizes to 1024×1024, and writes captions of the form `"cute cartoon illustration, <original caption>"` to `metadata.jsonl`. | §4.1.1 *Cartoon-style image dataset* |
| `scripts/04_train_lora.py` | LoRA fine-tuning of SDXL-base on the cartoon dataset (rank 4, α 4, lr 1e-4, 512×512, batch 1, grad-accum 4, ≤500 steps, AdamW, MPS, float32). | §4.1.1 / §4.2.1 (local fine-tuning); ablation **Table 9** (with vs without style adaptation) |
| `scripts/05_inference_with_lora.py` | SDXL-base + trained LoRA adapter inference, merged for speed. | §4.2.1 (style-adapted local generation) |

## Setup

```bash
cd Diffusion
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Run order

```bash
# 1. SDXL-Turbo baseline (Table 4 / Table 9) — no training needed
python scripts/01_sdxl_turbo_baseline.py

# 2. (optional) full SDXL-base reference
python scripts/02_sdxl_base_inference.py

# 3. Build the cartoon-style dataset (§4.1.1)
python scripts/03_prepare_cartoon_dataset.py

# 4. Train the cartoon-style LoRA
python scripts/04_train_lora.py

# 5. Generate with the trained LoRA
python scripts/05_inference_with_lora.py
```

## Notes

- `data/`, `outputs/`, and `lora_output/` are git-ignored: the dataset is
  regenerated by script 03, and images/adapters are produced by the runs.
- The deployed system uses DALL·E 3 (see `TikTalk-backend/`); this module is the
  local open-weight baseline used for comparison and ablation only.
- Reported SDXL-Turbo figure: ~3.5 s per image at 4 steps / 512×512, ~8 GB RAM
  (float32) on an Apple M4.
